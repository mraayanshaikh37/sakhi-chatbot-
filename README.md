# 🌸 Sakhi – AI Companion Chatbot

Sakhi is a simple web-based AI chatbot designed to provide a calm, supportive, and safe conversational space.  
It focuses on emotional support, basic safety guidance, and mental well-being conversations.

## Features
- Clean mobile-friendly UI
- Real-time AI responses using API
- Multi-line message input
- Scrollable chat interface
- Lightweight and fast

## Purpose
This project was created to explore:
- Frontend UI/UX design
- API integration
- Chatbot interaction flow
- Responsive design for mobile users

## Tech Stack
- HTML
- CSS
- JavaScript
- AI API (Mistral / similar)

## How to Use
1. Open the webpage.
2. Type your message.
3. Press **Send** or **Ctrl + Enter**.
4. Continue the conversation.

## Future Improvements
- Voice input
- Chat history storage
- Improved emotional response models
- Better accessibility support

## Disclaimer
This chatbot is for informational and conversational purposes only.  
It is **not** a replacement for professional medical or legal advice.
